## 1. Structural Pass

### 1.1 Wave Pattern (source: 03-storytelling-structure)

- [ ] Does the body start at ~70 intensity, not a slow warm-up?
- [ ] Does intensity spike to ~90 within the first 1-2 minutes?
- [ ] Are there wave cycles every 2-5 minutes? (Short-form: 2-3 waves max. Long-form 10-20 min: 4-6 cycles.)
- [ ] Is there a single-peak arc? If so → flag: restructure into waves.
- [ ] Does any section stay flat (no conflict, no contrast) for more than 2 minutes? Flag it.
- [ ] Is intensity at the 30-second mark above 50?

### 1.2 But/Therefore Flow (source: 03-storytelling-structure)

- [ ] Between every beat: does "but" or "therefore" belong, or is it "and then"? Replace all "and then" connections.
- [ ] Is there at least one "but" pivot per minute?
- [ ] Is the burn moment (single largest reversal) identified and placed as its own beat?
- [ ] Count: how many transitions use contrast words vs. passive segues?

### 1.3 The Dance (source: 03-storytelling-structure)

- [ ] Does the body alternate context beat → conflict beat → context beat → conflict beat?
- [ ] Are there two context beats strung together without a conflict between them? (reporter error)
- [ ] Does any conflict open without enough context for the viewer to care?

### 1.4 Reh-Hook Spacing (source: 02-reh-hooking)

- [ ] Does each body segment end with a reh-hook transition line?
- [ ] Does each reh-hook use a contrast word ("but," "however," "except") as the pivot?
- [ ] Cadence: reh-hooks every ~2-3 minutes on YouTube?
- [ ] Does each reh-hook reconnect to the original pain/solution gap (not just transition)?
- [ ] Does each reh-hook use the "and flip" mechanic: validate current point BUT open new problem?
- [ ] No body segment ends cold — every close either delivers the solve or teases the next problem.

### 1.5 Open Loops (source: 02-reh-hooking)

- [ ] At least one long-term loop opened early (for videos over 5 minutes)?
- [ ] Loop opener phrases distributed at ~60-90 second intervals?
- [ ] Every loop opener follows: validate previous + contrast word + tease next?
- [ ] Loop opener phrases are varied — not the same phrase repeated?
- [ ] Every opened loop is closed. Unclosed loops destroy trust.
- [ ] In a 10-minute video: approximately 7-10 loop openers needed.

### 1.6 Value Loop Completeness (source: 01-value-loop)

- [ ] Every body point has all three legs: Context (WHAT) → Application (HOW) → Framing (WHY)?
- [ ] Every Application step includes BOTH tech AND non-tech examples? (dual example rule — non-negotiable)
- [ ] Context test: can you state the concept in one sentence? If not, it's not clear enough.
- [ ] Framing test: does skipping it leave the viewer unsure why they need this?
- [ ] No Reporter-level sections: every stretch has contrast, conflict, or escalation.
- [ ] No Prince-in-Forest detours: the viewer has a clear destination at all times.

### 1.7 Point Sequencing (source: 01-value-loop)

- [ ] Body points ordered second-best first, best second (haymaker in position 2 or 3)?
- [ ] Body points anchored to high shock-score facts (80+ = body anchor material)?
- [ ] Does reading point 1 make you want to hear point 2?

### 1.8 Story Navigation (source: 03-storytelling-structure)

- [ ] At any random moment, can a viewer say exactly where they are? ("I'm at point 3 of 5, in the example section")
- [ ] Does each section open with a Hawkeye wide shot before narrowing?
- [ ] Does each section have a self-contained loop (opens and closes)?

### 1.9 Head Fakes (source: 03-storytelling-structure)

- [ ] At least one predictable outcome subverted?
- [ ] Is the false premise something the viewer already believes (not invented)?
- [ ] Does the redirect make sense retroactively (intriguing, not confusing)?

### 1.10 Reveal Quality (source: 03-storytelling-structure)

- [ ] For every body point: what is the reveal (the payoff the viewer is waiting for)?
- [ ] Test each reveal type: is it "better than expected" or "unexpected-intriguing"? (Only these two release dopamine.)
- [ ] Bear/unicycle test: does your reveal land as "a bear riding a unicycle" (unexpected-intriguing) or "a man walking a dog" (neutral)?
- [ ] If neutral → find a better fact or reframe so the prediction is wrong before the reveal lands.
- [ ] Confusing unexpected is the trap: surprising but no context = disorienting. Intriguing = surprising PLUS viewer wants to know why.

## 2. Language Pass

### 2.1 Jagged Line Test (source: 04-storytelling-language)

Run FIRST, before any other language editing.

- [ ] Print/view script: do sentence endings form an irregular edge (jagged), not a flat vertical?
- [ ] Any stretches of 4+ consecutive sentences at the same approximate length? Break them up.
- [ ] Is there variety across short (3-7 words), medium, and long (20+ words) sentences?
- [ ] Read aloud: where does your voice become monotonous? Mark and rewrite.
- [ ] Not over-corrected to all-short sentences (robotic choppy style)?

### 2.2 Active Voice (source: 04-storytelling-language)

- [ ] Search for passive markers: "was/were [past participle]," "is/are being," "has/have been."
- [ ] For each passive: rewrite by putting the subject before the verb.
- [ ] Exception: deliberate passive for emphasis or rhythm is acceptable — flag but don't auto-fix.

### 2.3 Contrast Words (source: 04-storytelling-language)

The family: but, actually, instead, turns out, except, yet.

- [ ] At least one contrast word per body section?
- [ ] At transitions involving contradiction or surprise: is a contrast word used (not "and," "also," "additionally")?
- [ ] "But" reserved for highest-stakes transitions (before burn moment, before head fake)?
- [ ] Any section goes multiple paragraphs without a contrast word? → flag (likely "and then" error).

### 2.4 Embedded Truths (source: 04-storytelling-language)

Qualifying words to eliminate: if, maybe, might, could, probably, potentially, possibly.

- [ ] Scan for all instances of qualifying words.
- [ ] "if you [action]" → "when you [action]"
- [ ] "this might work" → "the reason this works"
- [ ] "you could try" → "what you want to do is"
- [ ] Do not use embedded truths for claims you cannot support.

### 2.5 Thought Narration (source: 04-storytelling-language)

- [ ] At the 1-2 hardest-to-believe moments: has the script named what a skeptical viewer is thinking?
- [ ] Uses "You're probably thinking..." / "I bet you're wondering..." / "The question you're asking right now is..."?
- [ ] After naming: either validates ("that's a fair question") or addresses ("here's why that instinct is wrong")?
- [ ] Not overused — 1-2 instances per video section is sufficient.

### 2.6 Negative Frames (source: 04-storytelling-language)

- [ ] Any body points framed positively that feel flat? Test the negative version.
- [ ] Negative: "the worst thing you can do when trying to X" / "the mistake that kills Y"
- [ ] Does the negative version create more urgency? If yes, invert.

### 2.7 Conversational Tone (source: 04-storytelling-language)

- [ ] Would you say every sentence to a close friend in this exact form?
- [ ] No formal transitional phrases: "furthermore," "it is worth noting that," "as previously discussed"?
- [ ] Replace with: "here's the thing," "and here's where it gets interesting," or direct continuation.
- [ ] Contractions, casual conjunctions, direct questions present?
- [ ] Any sentence that sounds like a textbook, press release, or AI-generated content? → flag.

### 2.8 Vocabulary / Sixth Grade (source: 04-storytelling-language)

- [ ] Any word over 3 syllables that could be replaced with a simpler word?
- [ ] Target Flesch-Kincaid grade level 6 or below.
- [ ] Eliminate nominalizations ("implementation" → "doing it").
- [ ] If a technical term must stay: does it get the Explain Twice treatment immediately after?

### 2.9 Explain Twice (source: 04-storytelling-language)

- [ ] Every technical term re-explained with a metaphor?
- [ ] Pattern: "[technical explanation]. In other words — [metaphor / 5-year-old version]."
- [ ] Keep BOTH versions. Technical gives them the language; metaphor gives understanding.
- [ ] Applied after any counter-intuitive claim?

### 2.10 Atomic Messaging (source: 04-storytelling-language)

- [ ] For each body point: can it be stated in one sentence? If not, the idea isn't clear yet.
- [ ] Cut everything not in the irreducible version unless it serves comprehension.
- [ ] Every example: makes the concept clearer (keep) or just adds weight (cut)?

### 2.11 Direction (source: 04-storytelling-language)

- [ ] Does every section pull toward the last line?
- [ ] Any section feels like a detour? Cut it.

### 2.12 Three-Item Lists (source: 04-storytelling-language)

- [ ] Wherever multiple factors are described, compressed to exactly three items?
- [ ] Three-item groups scripted explicitly on one line (delivered as a rhythmic unit)?

Language editing order: Rhythm (2.1) → Clarity (2.2, 2.7, 2.8, 2.10) → Psychology (2.4, 2.5, 2.6, 2.3) → Comprehension (2.9, 2.11, 2.12)

## 3. Psychology Pass

### 3.1 Six Viewer Checkpoints (source: 06-psychology-attention)

1. **Pain accepted:** Does the hook make the viewer feel the problem? Specific, not vague?
2. **Trust:** Does the click confirm pass the BS detector? Proof within first 60 seconds?
3. **Plan of attack:** Is the plan (framework name + point count) stated before the body?
4. **Likability:** Does the body show genuine passion? Would the viewer like Fahad by minute 5?
5. **Paying attention:** Are reh-hooks and open loops managing attention throughout?
6. **Takes action:** Does the outro's CTA feel earned and natural (not bolted on)?

Timing standard: checkpoints 1-3 cleared within first 30 seconds.

### 3.2 Dopamine Formula (source: 06-psychology-attention)

Per body point, check for at least 2 of 3:
- **Value** — what the viewer is actually getting
- **Contrast** — distance between expected and delivered
- **Relevance** — how targeted at the specific viewer

If a point feels flat, identify which factor is missing.

### 3.3 Audience of One (source: 07-psychology-emotion)

- [ ] "You/I" audit: does "you" dominate throughout? (Benchmark: 9 "you" and 0 "I" in hook)
- [ ] Flag every instance of "people," "viewers," "creators" — replace with "you."
- [ ] Rewrite passive statements as direct address: not "the common mistake is..." but "the mistake you're making right now is..."
- [ ] Every sentence in first or third person: pressure-test for conversion to second-person.

### 3.4 Feeling Smart (source: 07-psychology-emotion, 08-psychology-trust)

- [ ] Can the viewer follow every complex concept with zero prior knowledge?
- [ ] Progressive disclosure: does complexity build gradually (simple framing first, then nuance)?
- [ ] No jargon without immediate definition?
- [ ] Metaphors bridge unfamiliar concepts to things the viewer already knows?
- [ ] 5-year-old test: when in doubt, re-explain at that level.

### 3.5 Desired Emotion (source: 07-psychology-emotion)

Six buckets — one dominant per video: awe, humor, excitement, anger, curiosity/shock, sadness/empathy.

- [ ] Is the target emotion written at the top of the outline?
- [ ] Does the script build toward this emotion throughout?
- [ ] Does the last dab deliver the peak of this emotion?
- [ ] Any sections that work against the target emotion? Flag them.
- [ ] Emotional transfer builds from beginning to end — resolution emotion stronger than pain emotion.

### 3.6 Pain Agitation (source: 07-psychology-emotion)

- [ ] Pain stated directly and bluntly: "if you've been struggling with" not "some people struggle with"?
- [ ] Emotional dimension added — not just what they're failing at, but what it feels like?
- [ ] FOMO: shows what people who solved it are experiencing?
- [ ] Pattern: agitate → empathize ("I've been there too").

### 3.7 Trust / Proof (source: 08-psychology-trust)

Proof hierarchy (ranked): (1) solved it for others, (2) done it yourself, (3) social scale, (4) transformation story, (5) common ground, (6) presentation quality.

- [ ] Highest available proof tier deployed within first 60 seconds of body?
- [ ] Proof flashed visually (screenshots, before/afters) — one or two, rapidly?
- [ ] Specific numbers in all results claims — no vague outcomes?
- [ ] BS detector resets at every new major claim — proof accompanies each?

### 3.8 Light Bulb Effect (source: 08-psychology-trust)

- [ ] At least two light bulb moments in the body (genuine "oh, I get it" reframes)?
- [ ] First light bulb moment: as close to 60 seconds as possible?
- [ ] Each is a reframe (new pattern from known things), not just a new fact?
- [ ] Whitespace around each light bulb moment — not buried in dense explanation?

### 3.9 CVS Test (source: 07-psychology-emotion)

After reading the full script, predict:
- [ ] **Super fan comment:** What would they be most excited to share? (blank = not inspiring enough)
- [ ] **Neutral comment:** What single observation would they comment? (blank = no clear POV)
- [ ] **Hater comment:** What would make them push back? (blank = no edge, no stance)

If any are blank, the script needs sharpening.

### 3.10 Energy / Mirror Effect (source: 08-psychology-trust)

- [ ] Delivery energy at 50% above what feels natural?
- [ ] Trust-critical sections planned for one-line-at-a-time recording?

### 3.11 Curiosity Amplitude (source: 06-psychology-attention)

- [ ] Each curiosity loop tied to a viewer pain they're actively experiencing (not abstract or trivial)?
- [ ] Use the viewer's actual pain language in loop openers, not your technical term?
- [ ] Loop duration calibrated to amplitude — high-amplitude (real pain) = hold longer; low-amplitude = close quickly?

### 3.12 Value Density (source: 06-psychology-attention)

- [ ] Is there anything in the body that could be cut without losing meaning?
- [ ] 60% compression test: if compressed to 60% length, does it lose essential meaning? If not, the original is insufficiently dense.
- [ ] Never pad to fill a length target.

### 3.13 Pavlovian Gate (source: 07-psychology-emotion)

- [ ] Does the script contain at least one reveal the viewer could not have predicted?
- [ ] "Does this video contain at least one thing the viewer couldn't have guessed?" If not, the script isn't finished.

## 4. Phase-Specific Checks

### 4.1 Hook Verification (source: 04-hook-psychology, 05-hook-mistakes)

**Four Commandments:**
- [ ] Alignment: visual, spoken, and text layers all say the same thing?
- [ ] Speed to Value: topic named in the first line? Nothing above it?
- [ ] Clarity: single topic, single question — would 50,000 viewers form the same question?
- [ ] Curiosity: hook opens a curiosity loop — viewer cannot not watch the next line?

**Four Mistakes (flag if present):**
- [ ] Delay: topic context comes too late? First line should name the topic.
- [ ] Confusion: every sentence parses on first listen? Subject → verb → revelation structure?
- [ ] Irrelevance: uses "you/your" framing? Viewer believes it's for them?
- [ ] Disinterest: creates contrast between A (current belief) and B (your alternative)?

**Additional hook checks:**
- [ ] BS Detector: specific numbers and relatable character, not general claims?
- [ ] 6 Power Words: subject, action, objective, contrast present? (proof and time optional)
- [ ] Ontarget Curiosity: does the viewer believe the topic is specifically for THEM? (distinct from irrelevance fix)
- [ ] One Std Dev Away: targeting the dream outcome adjacent to the pain, not pain directly?
- [ ] Cult Hopping: for niche/technical content, is there a familiar pop-culture or mainstream reference that bridges in?

### 4.2 Click Confirm Verification (source: click-confirm)

- [ ] First 1-2 sentences confirm what the title promised?
- [ ] One detail exceeds the base expectation (beats the title, not just meets it)?
- [ ] Credibility dropped as verbal aside ("by the way"), not a lede?
- [ ] Specific numbers and metrics, not vague claims?
- [ ] Framework named: "I call this..."?
- [ ] Point count stated explicitly? Does it match the actual body count?
- [ ] Outcome promise: "by the end of this you will..." — specific and verifiable?
- [ ] BS detector test: would a skeptical viewer trust this person enough to watch the body?
- [ ] Is the credibility signal earned and specific, or vague and self-promotional?
- [ ] Could the click confirm be trimmed without losing trust? (Cut to test what's load-bearing vs. padding)
- [ ] Length: 10-20 seconds, not 2 minutes?

### 4.3 Outro Verification (source: outro)

- [ ] Loop closed: explicitly states the hook's pain has been addressed?
- [ ] Recap: one line per point, compressed ordinal sweep ("first..., second..., third...")?
- [ ] Unexpected surprise: bonus tip/insight AFTER main content, framed as bonus?
- [ ] Emotional payoff: shifts from informational to relational tone?
- [ ] Last dab passes the share test: if the ONLY line someone heard, would they share it?
- [ ] Last dab placed BEFORE the sign-off (not the sign-off itself)?
- [ ] CTA anchored to a real body pain point (native embed, not bolted on)?
- [ ] CTA funnel: free resource before paid product?
- [ ] Comment invite: specific question, not generic "leave a comment"?
- [ ] Sign-off: consistent formula?
- [ ] Tone audit: does the outro feel like the restaurant's free chocolate, or an ad break?
- [ ] Short-form loop test: does the last line set up the first line if the video replays?
- [ ] Ends on a feeling, not on information?

## 5. Template Authenticity (unique to Phase 8)

No source guide — this is the review skill's signature diagnostic.

- [ ] Do template-sourced lines sound natural in context? (Read aloud test)
- [ ] Any leftover `[SWAP]` markers or placeholder text?
- [ ] Does the voice feel consistent throughout? (Kallaway templates → HitL voice after [SWAP])
- [ ] Do adjacent template-sourced lines flow naturally, or feel bolted together?
- [ ] Any overly mechanical phrasing that clearly came from fill-in-the-blank?
- [ ] Voice consistency: calm, friendly, practitioner, anti-hype throughout?
