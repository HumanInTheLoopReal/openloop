## Structure 2: The Layered Framework

### What It Is

A single named framework is the center of gravity. The video exists to install a mental model. Unlike the listicle (which enumerates parallel items), the framework has internal architecture: components that relate to each other, hierarchy, or a defined progression. The viewer leaves with a new conceptual lens, not just a list. You names and diagrams the framework explicitly, then walks each component. This structure appears across the most watched videos.

### Beat-by-Beat Flow

1. Hook: Framework existence teased ("there's a system nobody talks about," "I cracked the algorithm")
2. Click-confirm: Credibility + stakes ("here's what happens when you use it")
3. Framework introduction: Named, defined, optionally visualized (layers, ladder, matrix, wheel)
4. Component walkthrough: Each element of the framework fully explained with sub-tactics and examples
5. Integration section: How components interact / what order to apply them
6. Full-framework example: One real video/creator analyzed using the complete framework
7. Outro: Framework recap → where to start → CTA

### When to Use

Topics where a mental model dramatically clarifies an otherwise confusing domain. Best when there's genuine architecture to teach — not just a list, but a system where components interact. Requires the creator to have a named, proprietary framework (or to coin one). High rewatchability because viewers return to review the model.

### Variations

- **Ladder variant:** Levels that build cumulatively (storytelling levels, dopamine ladder). Implies mastery progression.
- **Matrix variant:** 2×2 or multi-axis grids (personal/brand × entertainment/education). Good for segmentation.
- **Formula variant:** Components that combine to produce an output (algorithm formula, hook formula). Scientific framing.
- **Loop/cycle variant:** Story loops, checkpoints. Implies repeatable process rather than fixed ladder.

### Signature Moves (Advanced Techniques)

- **The meta-demonstration move.** The most powerful framework videos use the framework *on the viewer while explaining it* — the psychology video uses psychology on you, the hook video uses its own hook structure on you. This is occasionally surfaced ("by the way the reason you're still watching is because I use this exact psychology hack to hook you") but never frames it as a structural technique to copy.
- **Naming components before defining them.** Always introduce a framework name first ("I call this the dopamine ladder"), then defines it. This naming-before-defining pattern primes curiosity and makes the definition land harder.
- **The "let's define this precisely" clarification move.** Before the component walkthrough, stop and nail down an exact definition ("we need a more objective definition for what cult-like behavior actually looks like"). This prevents the viewer from projecting the wrong mental model onto the framework.
